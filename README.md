# 幽霊道路マップ

決定から何十年もたった都市計画道路と、その計画線の上に建つ建物を地図で確かめるためのウェブマップです。アーバンデータチャレンジ2026 応募作品（エントリー番号306）。

- **浜松市の地図:** https://praveensaharan.github.io/yurei-doro-map/?city=22130
- **相模原市の地図:** https://praveensaharan.github.io/yurei-doro-map/?city=14150
- **全国96都市の一覧:** https://praveensaharan.github.io/yurei-doro-map/national.html

## できること
- 都市計画道路を、当初決定からの経過年数で色分けして表示します。
- 計画区域のうち、まだ道路になっていない部分（推定）を灰色の立体で表示します。
- 計画線内に建つ建物を赤で表示します（PLATEAU 建築物モデル、高さ付き）。
- 地理院の航空写真に切り替えて、現地の様子を確かめられます。
- 住所を入力するか地図をクリックすると、その場所が計画区域内かどうかと、都市計画法第53条の許可基準（その市の基準）を表示します。
- 共有用のリンク:
  - `?q=住所` で住所を検索した状態
  - `?at=緯度,経度` で地点を判定した状態
  - `?route=3・3・8` で路線を表示した状態
  - `&base=photo` を付けると航空写真で開きます

## 「道路化」の推定と検証
「道路化」は推定値で、市の公式な整備状況ではありません。次の手順で求めています。
1. 計画道路の中心線に沿って、10mごとに横断面をとります。
2. 各横断面で、計画幅員の2/3以上が既存の道路面（PLATEAU 道路モデル LOD1）になっていれば「道路になっている」とします。
3. 道路になっている横断面の延長の割合を「道路化」とします。

各市が公表している路線別の整備状況と比べました。

| | 浜松市（2012年の見直し資料） | 相模原市（2021年3月末の路線一覧） |
|---|---|---|
| 決定年の一致 | 51/51 路線 | 65/66 路線 |
| 整備済・一部・未整備の3区分の一致 | 29/35 路線 | 39/41 路線 |
| 差の中央値 | 10ポイント | 0ポイント |

差が大きかった路線は航空写真で確かめました。
- 浜松市の2路線（3・4・92、3・4・309）は2012年以降に整備されていて、推定は現在の状態と合っていました。
- 浜松市の2路線（3・5・210、3・5・79）は推定の誤りでした。
- 相模原市の橋本駅東通り線は、2021年以降に道路がなくなり、工事用地になっています。

相模原市の PLATEAU データでは、路線名と路線番号が市の一覧と合わない区間（267区間中64区間）がありました。照合には路線名を使い、名前と番号が合う区間を優先しています。

住所検索の位置は代表点（町丁目・街区）です。敷地ごとの正確な区域は、市の都市計画担当課で確認してください。
